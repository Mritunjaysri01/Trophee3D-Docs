# Setting up a Trophee SDK in Unity

This section will guide you through setting up a project to start monetizing your applications using the **Trophee SDK**. You'll need the Unity Game Engine and the latest version of the Trophee SDK package.

**Importing the SDK**

* Download the latest version of the **Trophee SDK** package from our developer portal.
* In Unity, navigate to **Assets -> Import Package -> Custom Package**.
* Select the Trophee SDK package file you downloaded and click 'Open'.
* In the Import Unity Package window, ensure all items are selected and click 'Import'.
