# Sign Up



* Sign Up at [https://trophee.live/partner/sign-up](https://trophee.live/partner/sign-up)

<figure><img src="../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure>

* Upon Successful Registration, you will be automatically sent to the Trophee Dashboard and a Unique Publisher Id will be assigned to you

<figure><img src="../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>

### Getting Publisher ID and Game ID :

* To use the SDK you need a Publisher ID which is unique to each developer and Game ID which is unique to each Game.
* Publisher ID is Automatically created Upon SignUp process and can be seen on the Top Right Corner of the Screen.
* To Get the Game Id one have to register the Game on the Dashboard.

### Registering the Game :&#x20;

* Navigate to the Game Management Section by clicking the Games option from left-hand menu&#x20;
* Click on Add New Game and fill the Required details&#x20;
* Upon filling the form, the Unique Game Id will be generated.
