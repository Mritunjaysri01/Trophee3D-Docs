# 🤌 BEST PRACTICES WILL LEAD TO GREAT RESULTS



1. Gaming partners (developers) should define the placeholders for the ‘Brand's product appearance, usually called the ‘Brand's icon’, within the game environment and at different game levels (like scorecard, game-over stage, game-pause stage, level over, etc.).
2. There should be a minimum of three (03) placeholders in a single game to leverage the monetization, and there should not be more than one (01) placeholder per screen. The number of placeholders should depend on the game length and the average time spent by the gamers.
3. There should not be any placeholder defined before 50 seconds (ideal 1 minute) from the start of the gameplay. This would help to engage efficiently with the active gamers.
4. The placements should be defined at the stage where the gamer is maximum engaged and where there are maximum eyeballs.
5. The size of the placeholders depends on the game type, and game developers can define it as per their game (please refer to the tech doc).
6. There are cool-off periods to avoid ad-fatigue to gamers and ad-frequency to leverage different brands in the game.
7. Game partners should share the basic details about their gamers to leverage the contextual brand fitment, like Demographic (male/female ratio); States contributing maximum gameplay session; Core TG (Age); Any unique preferences & pattern.
8. The solution should be integrated with the best and top-performing games to leverage the maximum benefits.
